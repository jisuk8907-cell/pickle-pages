# Pickle Pages

피클이 관리하는 전용 페이지 모음입니다.

- **투자 리포트 보드** — `/invest/` : A팀(뮤즈 · 인스팅트 · 큐 · 피클 PM)의 다각도 종목·시장 분석 보드

## 구성

| 경로 | 내용 |
|---|---|
| `/` | 페이지 목록(첫 화면) |
| `/invest/` | 투자 리포트 보드 (샘플 데이터 포함) |

## 리포트 추가

`invest/index.html`의 `REPORTS` 배열에 객체 1건을 추가하면 날짜별·종목별 목록과 차트에 자동 반영됩니다.
확인하지 못한 값은 추측 없이 `미확인`으로 표기합니다.

분석은 참고 자료이며 투자 조언이 아닙니다.
